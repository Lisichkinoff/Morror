# Morror 0.9.5

Morror now keeps the live phone preview updating when you move or resize its Windows window. This release also adds session recovery and makes it easier to move files between Windows and Android.

## Mirroring and second screen

- The main window and iPhone window have rounded corners and dark title bars. Start and Stop buttons use the same height.
- The home screen lets you choose Android mirroring, iPhone mirroring, or an Android second monitor. USB and Wi-Fi devices are listed separately.
- Use **Resume** after an unexpected disconnect to restart Android mirroring or the Android second monitor with the previous settings. Reconnect the device using the same connection first.
- Android mirroring shows measured FPS alongside the configured limit. The second-monitor window reports progress through the first frame, shows rendered FPS, and suggests lowering the resolution or switching to USB if low FPS persists.
- The second-monitor receiver is installed only when it is missing or older than the bundled APK.

## File transfers

- Send selected files to an authorized Android device from File Explorer's **Send to** menu. The Windows installer adds the shortcut.
- Select multiple items across pages in the Android gallery and save them to a folder on your PC. Batch downloads show progress, can be canceled, and preserve existing files when names collide.

## Downloads

- **Morror-0.9.5-Setup-win64.exe** is the Windows x64 installer.
- **Morror-0.9.5-win64.zip** is the portable Windows package. Extract the entire archive and run `Morror.exe`.
- **MorrorMonitor-0.9.5.apk** is the Android second-monitor receiver. Both Windows packages already include it.
- **SHA256SUMS.txt** contains SHA-256 checksums for the three packages.

Before updating manually, exit Morror from the Windows system tray. If you use Morror 0.9.3 or 0.9.4, you can also update through the built-in release check.
