# Morror 0.9.6

This release adds controls directly to the Android mirroring window, improves high-resolution rendering on Windows, and updates the app icon and window styling.

## Android mirroring

- Pin or unpin the stream, toggle fullscreen, copy a screenshot to the Windows clipboard, and stop mirroring from the toolbar. The toolbar follows the window as you move or resize it.
- Pinning stays in sync with the initial setting and fullscreen changes. Toolbar clicks are handled by Morror and keyboard focus stays with the stream.
- Direct3D 11 uploads large software-decoded frames without allocating staging textures for each plane. Hardware-decoded video alternates rendering textures for large frames. These changes apply at the selected resolution and FPS limit.
- The **Smooth** preset offers 720 px at up to 60 FPS with a 4 Mbps video bitrate. The toolbar continues to show measured FPS. Background device polling pauses during mirroring.

## Windows interface

- The new lavender **M** icon appears in the app, tray, mirroring windows and installer.
- Dark title bars and rounded corners now match across the main, iPhone, second-monitor, QR pairing and file-transfer windows.

## Downloads

- **Morror-0.9.6-Setup-win64.exe** is the Windows x64 installer.
- **Morror-0.9.6-win64.zip** is the portable Windows package. Extract the entire archive and run `Morror.exe`.
- **MorrorMonitor-0.9.6.apk** is the Android second-monitor receiver. Both Windows packages already include it.
- **SHA256SUMS.txt** contains SHA-256 checksums for the three packages.

Exit Morror from the Windows system tray before updating manually. Morror 0.9.5 can also update through its built-in release check.
