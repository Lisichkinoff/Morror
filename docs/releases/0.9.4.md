# Morror 0.9.4

Исправления звука Android по Wi-Fi и работы окна iPhone.

- Для Android по Wi-Fi добавлен звуковой буфер 120 мс, чтобы сглаживать кратковременные задержки сети и уменьшать заикания. Это немного увеличивает задержку звука; настройки USB и задержка управления не меняются.
- Исправлено повторное открытие окна iPhone: невидимое окно оформления больше не удерживает процесс после закрытия. Повторный запуск восстанавливает уже открытое окно.
- Окно iPhone открывается сразу в режиме AirPlay без предварительного поиска USB. Создание видеопредпросмотра вынесено из потока интерфейса.
- Добавлена кнопка «Настроить сеть AirPlay» с запросом прав администратора Windows. Правила ограничены встроенным приёмником, частной сетью и локальной подсетью. Блокировки для этого приёмника снимаются только с частного профиля.
- Добавлены подсказки о профиле сети Windows и подключении через «Пункт управления → Повтор экрана». Запуск приёмника больше не обозначается как подтверждённая доступность с телефона.
- Удалена лишняя предварительная проверка старого USB-драйвера; проверку подключения выполняет основной механизм захвата. Ошибки содержат подробности для диагностики.

## Установка

- **Morror-0.9.4-Setup-win64.exe** — установщик для Windows x64.
- **Morror-0.9.4-win64.zip** — portable-версия; распакуйте архив целиком и запустите Morror.exe.
- **MorrorMonitor-0.9.4.apk** — Android-приёмник второго монитора, также включён в Windows-пакеты. В этой версии APK обновлены только номер версии и код обновления.
- **SHA256SUMS.txt** — контрольные суммы файлов релиза.

Перед ручным обновлением закройте Morror через значок в трее. Версия 0.9.3 может получить обновление через встроенную проверку релизов.

Если Morror отсутствует в списке на iPhone: подключите оба устройства к одной сети, установите профиль «Частная» для доверенной домашней сети Windows, нажмите «Настроить сеть AirPlay», затем «Запустить AirPlay». На iPhone откройте «Пункт управления → Повтор экрана».

## Проверка

Проверены автоматические тесты приложения, жизненный цикл отдельного процесса iPhone и запуск/перезапуск встроенного AirPlay-приёмника. Проверка передачи изображения и звука на физических телефонах для этих исправлений не выполнялась.
